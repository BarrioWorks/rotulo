Check your site before you sign up

Pagehaven works with the finished website, the files a browser opens. It doesn’t run a build step.

  • Imports and edits

    HTML pages with their pictures, styles and fonts

    A page saved from an AI chat, an HTML template, or the built folder of a static site. Pagehaven finds index.html at the top of the ZIP, inside one folder, or in dist or build.

  • Imports, edits only part

    Sites whose pages are built in the browser by JavaScript

    A built React or Vite site publishes and works. You can only edit the text and pictures written in its HTML files, and Pagehaven warns you when you import it.

  • Refused

    Project code that still needs a build step

    A folder of source files, such as package.json and src, with no finished pages. Pagehaven says so and asks for the built website instead.

What you can change by clicking

Nothing goes live until you press Publish. Until then, every change is a draft only you see in the editor.

Words, headings and links
Type over any text written in your pages. Point a link at another page by picking its title from a list.
Photos
Replace a picture with a PNG, JPEG, GIF, WebP or AVIF up to 8 MB. Pagehaven reminds you to check the picture’s description.
Colours, sizes and spacing
Change text and background colour, font size and weight, alignment, padding and margins from a fixed set of controls.
Sections and pages
Hide, duplicate, move or remove a section. Add a page by copying one, or rename a page and its links follow.
Versions
Each publish is a numbered version. Make an earlier one live again, or start editing from it.

Questions before you import

Will my website work in Pagehaven?

If it is a folder of HTML pages, yes. If the ZIP holds source code instead, Pagehaven refuses it with this message: “This ZIP contains source code rather than a finished website. Export the built static website files and try again.” See what works.

Will editing break what the AI made?

Pagehaven changes only the part you edit. The rest of each page is published as you imported it. If an edit goes wrong, undo it, or make an earlier version live again.

Do I need to know HTML?

No. You click the part of the page you want to change, then choose Edit text, Style or Replace image from the controls next to it.

When do visitors see my changes?

Only after you press Publish and confirm. Pagehaven first shows the list of changes and the address visitors will use.

What happens to private files in my ZIP?

Pagehaven leaves out server code, private keys, password files and databases. It lists each file it left out with the reason, and warns you about secrets.

What if I forget my password?

Pagehaven can’t reset passwords yet. Use a password manager, and sign up with an email address you will keep.
