How do I get a ZIP of my website?

Ask for the finished static website, exported as a ZIP.

  • Look for index.html at the top, or inside dist or build.
  • Include the pictures, fonts and styles used by the pages.
  • Source code alone needs to be built before you can import it.
Lovable, Bolt or v0
These tools often download the project's code, which Pagehaven can't use on its own. Ask the tool, or whoever built your site, for the built website folder, then ZIP that folder.
Claude
Save the page as an .html file. Put it in a folder with any pictures it uses, rename it to index.html, and ZIP the folder.
An HTML template
Download the template's ZIP. Templates from sites such as Start Bootstrap already contain finished pages.
