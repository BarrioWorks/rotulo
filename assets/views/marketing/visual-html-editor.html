Start with the website’s HTML files

Rótulo is a visual HTML editor for websites delivered as finished files. That includes a page saved from an AI chat, an HTML template or a built static website folder. Include the pictures, stylesheets and fonts the pages use in the same ZIP.

A source project that still needs a build step cannot be imported as a finished website. If your download contains project code, ask its author or the original tool for the built static files. Check the HTML export requirements and ZIP examples before creating an account.

Change the content on the page

The screenshots below show the Furnace Hill Coffee sample website in the real Rótulo editor. Its original heading reads “Ten bags from Finca Los Naranjos”. After editing, it reads “Ten bags from Los Naranjos, and what they cost”. The page keeps its imported photo and typography.

Retype a heading or paragraph

Select text on the page and choose Edit text. Type the replacement where the text appears. Rótulo saves the change to your draft; publishing is a separate action.

Replace a photo and describe it

Select an image and choose Replace image to upload a PNG, JPEG, GIF, WebP or AVIF file up to 8 MB. You can also edit an image description or replace a background image. Choose a picture that fits the space in your existing design.

Change where a link goes

Select a link to change its destination. For example, a coffee shop’s button can point at a different page in its website. Review the destination before publishing, especially when you rename or remove pages.

Adjust a section or page

The style controls cover text and background colour, font size and weight, alignment, padding, and top and bottom margins. You can hide, move, duplicate or remove supported sections. You can also edit a page’s title and description.

Keep editing until the draft is ready

Changes save on their own. Undo and redo remain available across sessions, so you can return to an earlier edit after leaving the editor. Visitors see your changes only after you publish.

Publishing keeps a numbered version of the site. You can make an earlier version live again while keeping your current draft. See the preview, publish and version workflow for the steps between an edit and a live website.

What this visual editor cannot change

Rótulo edits content written in the HTML files. If your site’s JavaScript creates the content in the browser, the site can import and publish, but that generated content cannot be edited here.

Script and stylesheet contents, form controls, embedded frames, canvas drawings and maths are outside the editor’s supported edits. Sections containing scripts cannot be duplicated. The style controls use a fixed list of properties; they do not provide a free-form CSS editor.

You can add a page by copying an existing one, rename pages and delete pages. The home page cannot be renamed or deleted. This workflow suits changes to an existing site rather than building a new design from an empty page.

When to return to the original AI tool

For a new layout, a scripted interaction or content generated by JavaScript, return to the tool or person that built your site. Ask for finished HTML files when the work is done. Rótulo does not run the project’s build tools.

For a changed sentence, photo or destination in supported HTML, edit that part directly in Rótulo. The Rótulo homepage shows the import-to-publish workflow with the same sample site.
