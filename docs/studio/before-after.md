# Before and after

Both columns show Furnace Hill Coffee, the realistic blog in `fixtures/sites/furnace-hill/`. Before is the editor at commit `243c543` (`baseline/blog-screens/`). After is `main` (`final/screens/`). The full record, with task counts and measurements, is `evaluation/blog.md`. The earlier Agency template record is in `baseline/screens/`.

Some after screenshots were taken before the third fix round, which moved the caption above a heading when the text below would be covered and kept the site name in the page switcher. `evaluation/fixes3.md` has the measurements for that round.
