# Before and after

Before is `main` before the Studio round (`baseline/screens/`). After is the built redesign (`final/screens/`). Both use the same Agency template, except where a row says otherwise.

## Editor

| Before | After |
|---|---|
| ![Editor at rest, before](baseline/screens/editor-home-1280.png) | ![Editor at rest, after](final/screens/editor-resting-1280.png) |
| A 248 px sidebar holds pages, publishing, versions and the domain form. The site gets 67.7% of the window. | Three floating groups sit in a 52 px band above the site. The site gets 93.5% of the window. |
| ![Heading selected, before](baseline/screens/editor-heading-selected-1280.png) | ![Heading selected, after](final/screens/editor-heading-selected-1280.png) |
| A label chip and a separate icon toolbar. | One caption under the selection with the kind, the save state and worded actions. |
| ![Editing, before](baseline/screens/editor-heading-editing-1280.png) | ![Editing, after](final/screens/editor-editing-1280.png) |
| ![Page switcher, before](baseline/screens/editor-page-switcher-northwind-1280.png) | ![Page switcher, after](final/screens/editor-page-switcher-1280.png) |
| ![Images, before](baseline/screens/editor-images-list-1280.png) | ![Images, after](final/screens/editor-images-1280.png) |
| ![Settings, before](baseline/screens/editor-settings-1280.png) | ![Settings, after](final/screens/editor-settings-1280.png) |

## Tablet and phone

| Before | After |
|---|---|
| ![Tablet, before](baseline/screens/editor-heading-selected-834.png) | ![Tablet, after](final/screens/editor-heading-selected-834.png) |
